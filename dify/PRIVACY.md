# Privacy policy

This plugin sends the inputs you pass to its tools (files, text and parameters) to the pagespool API at https://api.pagespool.com over HTTPS, together with your API key if you set one, to run the operation you call, and returns the API's answer to Dify.

The plugin itself does not collect, store or log any data, and it sends nothing to any other third party.

pagespool processes the data it receives under its own privacy policy: https://pagespool.com/privacy
